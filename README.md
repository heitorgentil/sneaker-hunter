# Sneaker Hunter

O Sneaker Hunter é um projeto de um apaixonado por tênis, que, cansado de sair procurando os melhores achados e de fazer curadoria de site em site, decidiu criar uma ferramenta para fazer essa busca de forma inteligente e automatizada. As decisões vão continuar sendo questionáveis quando o assunto é comprar tênis, porque tênis nunca é demais, mas pelo menos agora isso vai ser suportado com dados (haha).

## Objetivo

O Sneaker Hunter nasce com o objetivo principal encurtar o caminho entre você e o seu mais novo objeto de desejo tenístico.
